# 0001 — Пайплайн рыночных данных (пилот F1)

- **Status**: accepted
- **Дата**: 2026-10-24
- **Ветка/этап**: F1 (сбор + парсинг + извлечение + аналитика; без профиля пользователя)

## Context

После создания спек 01–06 и дизайн-промптов (Stitch отложен — макеты перегружены)
решено укрепить фундамент данных до возврата к UI. Нужен реальный случай использования:
собрать вакансии djinni.co, распарсить, извлечь навыки и посмотреть статистику комбинаций
на живых данных. Профиль пользователя — отдельная система; рыночный анализ от него
не зависит (привязка — будущая надстройка).

Ключевые факты исследования (specs/02): серверный рендеринг, `/jobs/` разрешён robots.txt,
15 вакансий/страница, структурированные навыки только на detail-страницах,
JSON-LD `JobPosting` в `<head>` (иногда с `baseSalary`), дата обновления — «Оновлено …».

## Decision

Инфраструктура — CLI + Prisma (Next.js отложен), PostgreSQL 16 в Docker Compose
(SQLite исключён решением). Скрейп с жёсткой защитой от перегрузки.

| Параметр | Решение | Обоснование |
|---|---|---|
| Пауза между запросами | Случайная 3000–8000 мс (равномерно, `SCRAPE_DELAY_MIN_MS`/`SCRAPE_DELAY_MAX_MS`) | «Большая защита от перегрузки» (требование 2026-10-24); разброс интервалов маскирует скрейпер под нерегулярный трафик. Обновлено 2026-10-24: вместо фикс. 3000 мс ± 500 мс джиттер |
| Backoff | 10–160 с экспоненциально, до 5 попыток, на 429/403/5xx | Не усугублять блокировку |
| UA | Честный, с указанием бота (переопределяется env) | Прозрачность; блокировок при обычном UA не наблюдали |
| Лимиты запуска | `--pages` (default 5, страниц списка) и `--vacancies` (default 5, detail) — два отдельных параметра | Разные объекты с разной «ценой»; bulk и incremental — один скрипт |
| TTL списка | 1 день, общий на все страницы | Нумерация сдвигается при любых изменениях — инвалидация только пачкой |
| TTL деталей | 7 дней (конфиг.), приоритетнее `updatedAtDjinni` («Оновлено …») | Привязка к фактическому обновлению вакансии на djinni |
| Raw HTML | Всегда на диск (`cache/scrape/{list,detail}/`) | Перепарсинг (`pnpm parse`) без сети при правках парсера |
| Экстракция | 3 слоя без LLM: djinni_structured → djinni_extra → description_keyword | Словарное сопоставление (~200 записей с алиасами EN/UA); LLM — следующий шаг |
| Нераспознанные имена | `Skill(isCanonical=false)` + печать в лог | Не терять данные; кандидаты для курации словаря |
| Представления данных | Два: Postgres (приложение) + JSON/CSV-снапшот long-format (аналитика) | CSV «вакансия×навык» готов для pandas/кластеризации/LLM |
| Таксономия | Ручной словарь-файл `dictionary.ts`, alias-матчинг, lowercase | Детерминируемо, переиспользуемо, расширяемо; LLM-эмбеддинги — TBD |

Схема БД (Prisma): `JobPosting`, `Skill`, `JobSkillRequirement`, `RunLog` — подмножество
specs/05 БЕЗ User/Profile/Match (сознательное отступление: пользовательские сущности
добавляются с профильной надстройкой; `userId` появится там).

## Consequences / Trade-offs

- **Список и детали кэшируются раздельно**: свежий список может указывать на устаревшие
  детали — решается TTL 7 дней и приоритетом `updatedAtDjinni`.
- **`updatedAtDjinni` известен только после первого detail-парса** — до этого драйвер TTL
  отсутствует, работает чистый TTL.
- **Keyword-слой шумный** по определению (описания EN/UA, свободный текст) — весится
  nice-to-have (0.5), доминирует structured-слой.
- **Словарь требует курации**: авто-созданные `isCanonical=false` накапливаются —
  периодически переносить в `dictionary.ts`.
- **Bulk-обход ~6200 detail-страниц** при средней паузе ~5.5 с (случайной 3–8 с) ≈ 9–10 ч — одной командой не делается;
  планировщик/фоновые запуски — отдельная задача.

## Пилот (см. README, «Пилот: прогон на реальных данных»)

1. `pnpm install` + `docker compose up -d` (пользователь);
2. `pnpm db:migrate` + `pnpm seed:skills`;
3. `pnpm scrape -- --pages 2 --vacancies 10` → аудит;
4. `pnpm stats -- --skills React --window 30` → первый реальный кейс;
5. `pnpm export -- --window 30` → CSV/JSON для разбора;
6. добор до ~100–200 вакансий повторками `pnpm scrape -- --pages 5 --vacancies 25`.
